# Zone data licence (SrednaUK)

`zones.json` in this directory is generated by `scrapers/src/uk_sections.py`
from the average-speed sections published by
[speedcameramap.uk](https://speedcameramap.uk/data-sources/), which are
extracted monthly from OpenStreetMap.

**© OpenStreetMap contributors.** The data is available under the
[Open Database License (ODbL) 1.0](https://opendatacommons.org/licenses/odbl/1-0/).
`zones.json` is a derived database and is likewise made available under
ODbL 1.0. The raw inputs are kept in `scrapers/data/uk/`.

This licence covers the data only; the app source code remains under the
MIT licence in the repository root.

Missing or wrong zones are best fixed at the source: edit the
`enforcement=average_speed` relation on OpenStreetMap and the next monthly
refresh (`cd scrapers && python -m src.uk_sections`) picks it up.
